# 홈페이지 양도 가이드 (대표님용)

현재 사이트는 정적 HTML이라 **서버·DB·월 사용료가 없습니다.** 코드는 GitHub 저장소에, 공개는 GitHub Pages(무료)로 하고 있습니다.
양도할 것은 세 가지입니다: ① 코드 저장소 ② 도메인(주소) ③ 외부 서비스 계정.

## 1. 코드 저장소 — GitHub 계정 이전

1. 대표님이 github.com 에서 계정 생성 (회사 메일 `5000220@daum.net` 권장, **2단계 인증 켜기**).
2. 현재 소유자(yunho1110)가 저장소 `JS-E-G` → Settings → 맨 아래 *Danger Zone* → **Transfer ownership** → 대표님 계정 입력.
3. 대표님이 이메일로 온 이전 요청을 수락.
4. 이전 후 `Settings → Pages` 에서 *Deploy from a branch → main / (root)* 가 켜져 있는지 확인.
5. 이전하면 주소가 `https://<대표님계정>.github.io/JS-E-G/` 로 바뀝니다 (옛 주소는 연결되지 않음). 도메인을 쓰면 영향 없음 → 2번 권장.

> 저장소는 **Public** 이어야 무료 Pages가 됩니다. 비공개로 두려면 GitHub 유료 플랜이 필요합니다. 사이트에는 비밀번호·키가 없습니다.
> 개발자가 계속 수정하려면 대표님이 저장소 *Settings → Collaborators* 에서 개발자 계정을 추가하면 됩니다.

## 2. 도메인 (회사 명의로 구매)

1. 가비아·후이즈·호스팅케이알 등에서 `jungsu-eng.co.kr` 같은 도메인을 **대표님(사업자) 명의·결제**로 구매 (연 1~3만 원대). `.co.kr` 은 사업자등록증(202-16-19237)이 필요합니다.
2. 도메인 DNS 설정에 아래를 입력:
   - `A` 레코드 (호스트 `@`): `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` (호스트 `www`): `<대표님계정>.github.io`
3. GitHub 저장소 → Settings → Pages → *Custom domain* 에 도메인 입력 → 저장 (저장소에 `CNAME` 파일이 자동 생성됨). 인증서 발급 후 **Enforce HTTPS** 체크 (최대 수 시간).
4. 구매 계정(아이디·비밀번호)과 **자동 연장 결제 카드**는 대표님이 보관. 만료되면 사이트가 내려갑니다.

## 4. 이후 수정은 어떻게?

- 사진 교체: `assets/img/real/` 에 같은 이름으로 jpg/webp/avif 덮어쓰기 (`assets/img/README.md` 참고).
- 문구 수정: 각 폴더의 `index.html` 에서 `「 」` 로 표시된 값(준공일·용량 등)을 실제 값으로 변경 후 `python3 tools/build_en.py && python3 tools/bust.py`.
- 간단한 수정은 GitHub 웹에서 파일 연필 아이콘으로 직접 편집 → Commit 하면 1~2분 내 반영됩니다.
