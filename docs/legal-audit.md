## ⑥ 공개 전 최종 조치

**반드시**
1. ⑤의 책임자 · 시행일 · 보유기간 입력 (`「 」`로 표시된 곳 전부 — `grep -rn "「" privacy policy`)
2. ESS · 제품 · 뉴스의 시안(AI · Unsplash) 이미지를 실제 사진으로 교체하거나 해당 페이지 비공개
3. `docs/meeting-notes.md`는 저장소에서 삭제함(2026-11-12). 단 기존 커밋 이력에는 남아 있으므로 민감하면 이력 정리 또는 비공개 저장소 이전이 필요. `docs/greeting-draft.md`(인사말 초안)도 공개해도 되는지 확인
4. 이 브랜치 첫 커밋(번호판 흐림 처리 전 원본 사진 포함)이 이력에 남아 있음 — 필요하면 브랜치 이력을 정리한 뒤 병합

**권장**
- 처리방침 · 법령 최신본 대조 (개정 개인정보 보호법 시행일 포함)
- 실제 서버 접수 폼(Formspree 등) 도입 시 처리방침 · 위탁 · 국외 이전 항목 갱신
